# deep_tainan_house 台南購屋深度分析

用 Tkinter 寫的桌面／平板工具：在台南的衛星影像或 3D 地形上看各區房價與近半年起伏，用預算和通勤距離篩選行政區，
並整理捷運、大型開發、議會與建商情資。只用 Python 標準函式庫就能執行；裝了 Pillow 會多出衛星影像、疊圖與高解析影像。

## 怎麼執行

**Windows 電腦**：在這個資料夾按兩下 `run_app.bat`，或在命令列輸入 `python app.py`。

**三星平板（Android）**：
1. 到 Play 商店安裝「Pydroid 3 - IDE for Python 3」（免費）。
2. 把整個 `deep_tainan_house` 資料夾複製到平板（USB 傳輸線、Google 雲端硬碟，或把對話裡的 zip 檔下載後解壓縮）。
3. 開啟 Pydroid 3 → 左上選單 → Open → 選 `deep_tainan_house/app.py` → 按右下角黃色播放鍵。
4. 想要衛星影像底圖：Pydroid 3 左上選單 → Pip → 輸入 `pillow` → Install，裝好後重新執行。沒裝也能用，只是底圖是立體地形。
5. 第一次開啟若字太小或太大，按右上角「字 ＋／字 －」；3D 轉動不順就把「3D 畫質」改成「標準」或「省電」。

只是想把畫面「秀」在平板上、不在平板上安裝任何東西：在電腦和平板都裝 Chrome 遠端桌面（或類似的遠端工具），
用平板連回電腦操作同一個視窗即可，觸控拖曳一樣能旋轉地圖。

## 五個分頁

| 分頁 | 做什麼 |
|---|---|
| 3D 房價地圖 | 各區房價柱、近半年走勢、預算與通勤篩選、風險疊圖、路段行情、逐筆成交 |
| 區域比較 | 2～3 個行政區並排：單價、總價、起伏、預售屋、捷運、開發案、到上班地點的距離 |
| 捷運與鐵路 | 各規劃線的進度、時程、議會決議（附來源） |
| 開發與情資 | 大型商辦／園區／重劃區、議會、建商動向、市況（附來源） |
| 看屋清單 | 自己在看的房子：新增、編輯、刪除、標在地圖上，並自動和實價登錄行情比較 |

## 地圖操作

| 動作 | 電腦 | 平板 |
|---|---|---|
| 移動地圖 | 按住左鍵拖曳（地面跟著游標走） | 單指拖曳 |
| 旋轉地圖 | 按住右鍵（或 Shift＋左鍵）拖曳；或按「左轉／右轉／俯視／平視」 | 按「左轉／右轉／俯視／平視」，或先把「拖曳：平移」切成「拖曳：旋轉」再拖曳 |
| 放大縮小 | 滾輪，**對著游標的位置縮放**：游標移到想看的地方再滾，就會往那裡拉近 | 「放大」「縮小」按鈕 |
| 看某一區 | 點房價柱或右側排行，地圖會自動滑到那一區並拉近 | 同左 |
| 看地標、開發案、車站 | 點一下，地圖會把它滑到畫面中央並拉近 | 同左 |
| 回到整個臺南市 | 右上的「全市總覽」（保留旋轉角度）或下方的「重置」（連角度一起還原） | 同左 |

「拖曳」按鈕可以把左右鍵對調（左鍵旋轉、右鍵平移），習慣舊版操作的話按一下就好。

工具列平常只有一排：房型（全部合併／透天厝／大樓華廈／預售屋）、柱高（單價／總價）、顏色（價格高低／近半年漲跌）、底圖。
右邊兩個按鈕各展開一列，再按一次收起來（開合狀態會記住）：

* **圖層 ▼**：捷運、開發案、看屋圖釘、標籤、路段房價、地標的開關，以及疊圖（區界、路名、土壤液化、活動斷層）、液化濃淡、高解析影像。
* **篩選 ▼**：總價預算、房貸試算、上班地點 A／B。設了條件後，按鈕上會直接顯示「符合 N 區」。

其他：

* 視窗變窄或字放大時，工具列會自動換行，不會被切到畫面外。
* 地圖左上角的「圖例」點一下可以收合成小標籤，再點一下展開。
* 「更新實價登錄」按鈕和資料狀態在視窗最下方。
* 畫面高度相對字級不夠時（平板、小螢幕、字放得很大），右側的走勢圖會收進「走勢」分頁，讓排行、路段、成交清單有足夠的空間。

## 預算、房貸與通勤

* **總價預算**：按「篩選」展開後填數字（萬）再按 Enter。各區的中位總價高於預算的，房價柱會縮成貼地的灰色小方塊，
  排行裡排到後面；「篩選」按鈕上顯示「符合 N 區」。
  比的是「該區中位總價」，代表那一區有一半的成交低於這個價格，不是買不買得到的保證。
* **房貸試算**：填總價、成數、利率、年限，算出自備款、每月應繳（本息平均攤還）與利息總額。
  這只是算術，利率與成數請填銀行實際給的條件；沒有算寬限期、稅費與保險。
* **上班地點＋公里內**：從清單選（南科、沙崙、成大醫院、各工業區等 12 個），或選「在地圖上點選…」後在地圖點一下。
  地圖會畫出範圍圈，範圍外的區縮成貼地的灰色小方塊；排行多一欄「距離」。距離是行政區中心到上班地點的**直線距離**，
  實際車程請選一個區後按右側「通勤路線」，用 Google 地圖查。
* **兩個上班地點**：A、B 可以各設一個（例如兩個人各自通勤）。兩個都填了公里數時，要兩邊都在範圍內才算符合；
  地圖上有兩個圖釘和兩個範圍圈，排行同時列出「距A」「距B」（點欄位標題可依該距離排序），
  「通勤路線」會各開一個 Google 地圖分頁。只想看距離、不想篩選時，公里數留空即可。
* 「清除條件」一次清掉預算與通勤設定。條件會記住，下次開啟還在。

## 區域比較

在地圖選一個區後按「加入比較」，或直接在「區域比較」分頁用下拉選單挑 2～3 區。上方是每月中位價走勢疊圖，
下方表格並排列出各房型價格、半年起伏、預售屋對中古大樓的價差、最近的捷運規劃站、影響度 4 以上的開發案。

## 細到路名的房價

需要逐筆成交資料，**要先按過一次「更新實價登錄」**。

* **在地圖上看**：選一個行政區，地圖上會把近一年有成交的路段依中位價上色（黃 → 橘 → 紫紅，越深越貴），
  放大後每條路旁邊會標出「路名＋價格」。滑鼠移到路上有說明，點一下右側就列出那條路的逐筆成交。
  柱高選「單價」時標的是中位單價（萬/坪），選「總價」時是中位總價（萬）。
* **在清單看**：右側「路段」分頁列出該區所有有成交的路段（件數、中位單價、中位總價、最近成交年月）；
  點一列，地圖會移到那條路並把它標出來。
* **用路名搜尋全市**：回到「全市總覽」，在「路段」分頁的「搜尋路名」輸入例如「中山路」，
  會列出各區同名路段的行情；點一列會跳到該區。
* 道路的位置取自 OpenStreetMap（實價登錄只有門牌文字、沒有座標）。每個行政區第一次查看時會自動下載一次
  （約 0.5～2MB、幾秒鐘），存在 `data/cache/roads/`，之後離線可用。公開伺服器偶爾忙線，
  程式會換伺服器重試，最多等一分半鐘；下載失敗時右側清單照常可用，把「圖層」裡的「路段房價」取消再勾選即可重試。
  每次下載成功或失敗的原因都記在 `data/cache/roads/_log.txt`。
* 門牌如果不是路名而是聚落名稱（例如善化區的「茄拔」「小新營」），地圖上畫成一個圓點，位置是聚落的大概位置。
* 不到 3 件的路段名稱後面有 `*`，中位數只供參考。預售屋是以建案分組，不畫在地圖上。
* 第一次成功下載一區之後，程式會在背景一區一區把其他行政區的道路位置也抓好（每區之間停幾秒，不影響操作），
  之後換區、搜尋地址就不用等。

## 搜尋地址與門牌圖釘

* **地圖上方的搜尋框**：輸入地址或路名後按 Enter（或「搜尋」），例如
  「善化區中山路123號」「中西區大同路一段46巷50號」「大同路一段」「善化中正路」。
  地圖會滑到那一段並插上粉紅色圖釘，右邊「成交」分頁列出價格：最上面是摘要（同門牌、同一條巷、整條路各幾筆、中位單價與總價），
  下面的清單依門牌遠近排列，深色底是同門牌、淺色底是同一條巷。
* 沒寫行政區、而好幾區都有同名的路（例如「中山路」）：右邊「路段」分頁會列出各區，點要看的那一區就會過去。
* 也可以直接輸入行政區（「安平」）或地標（「赤崁樓」）。
* **點「成交」清單的任何一列**：地圖會用圖釘標出那一筆的大概位置，圖釘周圍的虛線圈是誤差範圍。
* 實價登錄沒有座標，免費的地址查詢服務對台灣門牌也只認得到路名，所以位置是用 OpenStreetMap 的道路推估的，準確度依序是：
  巷子或弄在 OpenStreetMap 上有 → 沿著巷子依門牌號碼推估（誤差約數十公尺）；
  路上有好幾個「○巷」的巷口 → 用巷口的號碼當刻度內插門牌（誤差約一兩百公尺）；
  聚落式門牌 → 聚落的大概位置；其餘 → 那條路的中段。滑鼠移到圖釘上會顯示是哪一種。

## 地標

地圖上的立體小圖案是台南的知名地標（赤崁樓、安平古堡、奇美博物館、高鐵台南站、七股鹽山、烏山頭水庫等約 27 處），
方便辨認方位。滑鼠移上去有名稱，點一下右側有簡介。圖案是示意造型，不是建築物的精確模型。
縮小時擠在一起的地標只顯示比較知名的，放大後其他的才出現；不想看可以在「圖層」取消「地標」。
要增減地標可編輯 `data/landmarks.json`（名稱、座標、造型種類、簡介）。

## 重大建設（3D 圖案與年份滑桿）

* 有時程的開發案（台積電新廠、南科特定區、鐵路地下化、捷運藍線、北外環、Costco 二店、社會住宅等三十多項）
  在地圖上畫成立體小圖案：晶圓廠、大樓、重劃街廓、廠房、交流道、捷運高架站、商場等造型。
* 顏色代表狀態：**原色＝完工／營運中、旁邊有黃色塔吊＝施工中、淡色＝規劃中**。圖例裡有說明。
* 地圖下方的 **「建設年份」滑桿**可以從今年拉到 9 年後：拉到 2030，就看到那時候哪些已經完工、哪些還在蓋。
  年份來自各項「時程」裡寫的動工、完工年（依報導與官方說法，常會延後）；寫「未定」的就一直是規劃中。
* 點圖案：右邊「點選」分頁列出時程、所拉年份的狀態、所在區的中位單價與近半年漲跌，以及完整情資與來源。
* 「圖層」裡的「重大建設 3D」可以關掉，關掉後這些建設恢復成菱形標記。
* 時程欄位在 `data/intel.json` 每一項的 `build`（`model` 造型、`phase` 現況、`start`／`done` 年份、`note` 依據），
  每週自動更新情資時會一併維護。

## 行情報告（給房仲或自己存檔）

* 選一個行政區，或在搜尋框找一個地址，再按右上的 **「行情報告」**，可以填製作人（房仲）名稱、電話、客戶稱呼與備註。
* 會產生一頁報告存在程式資料夾的 `reports/`，並用瀏覽器打開，按上方「列印／存成 PDF」就能存檔或傳給客戶。
* 內容：重點數字（中位單價、總價、近半年起伏、預售比中古）、每月走勢圖、
  搜尋的地址附近（同門牌、同巷、整條路）的成交、最近 30 筆成交、5 公里內的重大建設與完工年份、到上班地點的距離。
* 名稱與電話會記住，下次不用再填。

## 預售屋

* 房型選「預售屋」會改用實價登錄的預售屋申報資料（已解約的不計）。「全部合併」只含成屋買賣，不含預售。
* 右側「路段」分頁在預售屋模式下列的是各建案的件數與中位價，點一列看該建案的逐筆成交。
* 需要逐筆資料，要先按一次「更新實價登錄」。

## 看屋清單

* 「新增物件」填名稱、行政區、類型、總價、坪數（其餘選填），右邊會顯示它比該區同類型的中位總價、中位單價高或低多少；
  更新實價登錄後還會顯示同一路段的行情。
* 「在地圖上標位置」→ 在地圖點一下，物件就以紫色圖釘出現在 3D 地圖上；點圖釘會跳回清單。
* 資料存在 `data/watchlist.json`。清單裡一開始的 6 筆是從舊的 `house_data.py` 帶過來的示意資料（地址只有路名），
  可以直接刪除或編輯成真正在看的房子。
* 開價通常高於成交價；行情是整區的中位數，屋況、地坪、臨路條件不同都會有差距。

## 疊圖與風險圖層（需要 Pillow 與衛星底圖）

按「圖層」展開後的「疊圖」，第一次勾選時會下載該圖層（各約數 MB），之後離線可用：

| 疊圖 | 內容 | 資料來源 |
|---|---|---|
| 區界 | 行政區界線 | 內政部國土測繪中心 |
| 路名 | 道路與地名（透明底） | 內政部國土測繪中心 |
| 土壤液化 | 液化潛勢高（紅）／中（黃）／低（綠） | 經濟部地質調查及礦業管理中心、臺南市政府 |
| 活動斷層 | 斷層線與斷層地質敏感區 | 經濟部地質調查及礦業管理中心 |

* 土壤液化潛勢表示**強震時**土壤可能液化的輕重程度，不是平時就有危險；公開圖資精度有限，不能代表每一塊土地，
  個別建物仍要看地質鑽探與基礎設計。
* 活動斷層線是斷層跡的大致位置，不等於地震危險度高低。
* **淹水潛勢沒有做進 App**：官方圖資服務從外部連不上，而且依規定僅供防救災使用。
  請按「淹水潛勢↗」到國家災害防救科技中心的 3D 災害潛勢地圖查看。
* **高解析**：勾選時，把地圖放大（右下角比例尺顯示 2 公里以下），會在背景自動下載該處更清楚的航照（存在 `data/cache/tiles/`），
  看得到街廓與建物。需要網路；沒有網路時維持原本的解析度。
* **液化濃淡**：土壤液化圖層預設調淡，才看得到底下的衛星影像；用「圖層」列的滑桿可以調濃或調淡。
* 拖曳地圖時疊圖是預先合成好的，開很多層也不會變慢；剛勾選或調整濃淡後會停頓不到一秒重新合成。

## 房價資料

* 來源：內政部不動產交易實價查詢服務網的開放資料（臺南市不動產買賣、預售屋買賣）。
* 內建一份快照（2026-09-21 發布為止），不用上網就能看各區統計。
* 按右上角「更新實價登錄」會從官方網站下載最新資料並重新統計；第一次約 100～150MB，之後只補新的。
  **從舊版升級後第一次更新，會重新下載最近幾期的壓縮檔（約 120MB）以補上預售屋資料，只需要一次。**
* 統計口徑：只算住宅的房地交易，排除親友、持分、急買急賣等特殊交易；數值都是中位數。
* 實價登錄從成交到公開約慢 1～2 個月，最近一個月件數偏少（圖上用空心點表示）。
* 「近半年起伏」＝後 3 個月中位數 ÷ 前 3 個月中位數；兩段各少於 10 件就不計算。
* 透天厝單價是用建物面積算的（價格含土地），看透天請以總價為主。
* **自動更新**：內政部每月 1、11、21 日發布新一期。只要下載過一次逐筆資料，之後開程式時會自動檢查，
  有新的一期就在背景補抓（通常十幾 MB、不跳視窗、不影響操作），程式一直開著也會每 6 小時檢查一次。
  右下角的「自動更新」可以關掉；第一次完整下載（約 120MB）還是要自己按「更新實價登錄」。
  自動更新失敗時狀態列會說明，當天不再重試、隔天再試。

## 衛星影像底圖

* 上方「底圖」可選「衛星影像」或「立體地形」。預設是衛星影像。
* 影像是內政部國土測繪中心的正射影像（航照圖），免金鑰。第一次開啟時會在背景下載（電腦約 225 張圖磚、8MB；
  平板約 64 張、2MB），下載完自動切換，之後存在 `data/cache/basemap/`，不用再連網。
* 要把 Google 衛星圖放進 App 必須申請 Google Maps API 金鑰（需綁信用卡）；沒有金鑰時 Google 的條款不允許直接抓它的圖磚，
  所以改用這份政府開放影像。要看 Google 的版本請按右側「Google 衛星圖」按鈕。
* 衛星影像模式下地面是平的（影像無法貼在起伏的網格上），房價柱、捷運線、開發案照常顯示；要看山勢起伏切到「立體地形」。
* 需要 Pillow 套件（`pip install pillow`）。沒有安裝、沒有網路或下載失敗時，會自動顯示立體地形。

## 情資每週自動更新

* 捷運、開發案、議會與建商情資放在 `data/mrt.json` 與 `data/intel.json`，每一筆都附來源連結。
* Claude 的排程工作「台南購屋情資每週更新」每週一早上會重新查證並更新這兩個檔案（電腦要開著、Claude 桌面版要在執行）。
  更新前的版本會備份在 `data/backup/`，每次改了什麼寫在 `data/update_log/`。App 下次開啟時就會讀到新資料。
* 平板上的副本不會自動更新；要同步時把電腦上的 `data/intel.json`、`data/mrt.json` 複製過去即可。
* 自己手動改過這兩個檔案後，執行 `python tools/check_data.py` 檢查格式，最後一行顯示「資料格式正確」才算沒問題。

## 網頁版（手機、平板都能用，放在 GitHub Pages）

`web/` 資料夾是網頁版：打開網址就能用，所有計算都在使用者自己的手機或平板上完成，不需要伺服器，你的電腦也不用開著。
功能：各區房價 3D 地圖（單指拖曳移動、雙指縮放旋轉、兩指上下滑調整俯角）、地址搜尋與門牌圖釘、各路段行情、逐筆成交、
重大建設 3D 與年份滑桿、地標、捷運、土壤液化與斷層圖層、預算與通勤篩選、看屋清單（只存在那台裝置的瀏覽器，可匯出備份）。
在手機瀏覽器選「加到主畫面」，之後就像 App 一樣開啟。

### 第一次上傳到 GitHub

```
cd deep_tainan_house
git init -b main
git add .
git commit -m "台南購屋分析：桌面版與網頁版"
git remote add origin https://github.com/你的帳號/tainan-house.git
git push -u origin main
```

`.gitignore` 已經排除個人資料（`data/settings.json` 上班地點、`data/watchlist.json` 看屋清單、`data/backup/`、`reports/`）
與快取（`data/cache/`），不會傳上去。上傳前可以用 `git status` 再確認一次。

接著到 GitHub 專案頁 → **Settings → Pages → Source 選「GitHub Actions」**。
之後每次 `git push`，GitHub 會自動部署，一兩分鐘後網址 `https://你的帳號.github.io/tainan-house/` 就是最新版。
（GitHub Pages 免費方案需要專案設為 Public；程式裡沒有密碼或金鑰，個人資料也都排除了。）

### 資料怎麼更新

* **實價登錄**：GitHub 會在每月 2、12、22 日自動下載新一期、重新統計並更新網頁（`.github/workflows/pages.yml`），
  更新後的資料會 commit 回專案，記得在電腦上 `git pull`。也可以在 GitHub 的 Actions 頁面手動按「Run workflow」。
* **情資、捷運**（每週一的排程會改 `data/intel.json`、`data/mrt.json`）：在電腦上 `git add data && git commit && git push`，網頁就會更新。
* **在電腦上重新產生網頁資料**（例如剛按過桌面版的「更新實價登錄」）：`python tools/export_web.py`，再 commit、push。
  加 `--no-images` 可以略過重做底圖。

### 在電腦上預覽

`python -m http.server 8000 --directory web`，再用瀏覽器開 http://localhost:8000 。（直接雙擊 index.html 不行。）

## 怎麼測試

1. **自動測試**：按兩下 `run_tests.bat`（或 `python tests/run_all.py`）。平板上用 Pydroid 3 開啟 `tests/run_all.py` 執行。
   最後一行出現「全部通過」即正常（電腦上約需一分半鐘，過程中會有視窗自己開開關關）。
   完整結果也會存到 `tests/last_result.txt`，有問題時把那個檔案的內容貼出來即可。測試會把每個分頁、37 個行政區、每筆情資都點過一遍，並用假資料模擬
   更新實價登錄、下載衛星底圖與疊圖、預算與通勤篩選、看屋清單的新增／編輯／刪除。
   測試一律使用內建快照與空白設定，**不會讀取或改動你電腦上的快取、設定與看屋清單，也不會連網**。
2. **手動檢查清單**（電腦與平板各做一次）：
   - [ ] 開啟後看得到地圖、橘色房價柱、捷運線與菱形標記；第一次開啟約十幾秒後底圖自動變成衛星影像
   - [ ] 「底圖」切到「立體地形」再切回「衛星影像」都正常
   - [ ] 左鍵拖曳可移動地圖、右鍵拖曳可旋轉；滾輪對著游標的位置放大縮小，畫面是滑過去的不會跳
   - [ ] 點「赤崁樓」的圖案（或任何地標、菱形標記），地圖會滑到那裡並拉近
   - [ ] 搜尋框輸入「善化區中正路667巷5號」按 Enter：地圖移到那裡並插上圖釘，右邊「成交」上方有價格摘要
   - [ ] 在「成交」清單點任何一列，地圖上的圖釘移到那一筆的大概位置
   - [ ] 地圖上看得到重大建設的 3D 圖案（施工中有黃色塔吊）；把下方「建設年份」拉到最右邊，部分建設變成完工的顏色
   - [ ] 選善化區按「行情報告」→「產生報告」，瀏覽器打開一頁報告，可以列印成 PDF
   - [ ] 點「善化區」的柱子，右側變成善化區的數字與走勢圖
   - [ ] 顏色切到「近半年漲跌」，柱子變成紅（漲）／藍（跌）／灰（持平或樣本不足）

   - [ ] 上班地點 A、B 各選一個並填公里數，地圖出現兩個範圍圈，排行有「距A」「距B」兩欄
   - [ ] 「圖層」「篩選」兩列可以展開、收起；把視窗拉窄，工具列自動換行

   - [ ] 回「全市總覽」，在「路段」分頁搜尋「中山路」，列出各區的中山路行情
   - [ ] 地圖上看得到赤崁樓、安平古堡、七股鹽山等立體地標，點一下右側有簡介
   - [ ] 上班地點選「南科台南園區」、填 10 公里，地圖出現範圍圈與黑色圖釘

## 已知限制

* 捷運站位、開發案位置、上班地點與行政區座標都是估算值，僅供示意。
* 通勤距離是直線距離，不是車程。
* 路段房價是把門牌上的路名對到 OpenStreetMap 的道路；同一條路很長時，整條路是同一個中位價，看不出路頭路尾的差別。
* 門牌圖釘是推估的位置（見「搜尋地址與門牌圖釘」），不是門牌的精確座標；要確認請按「Google 地圖」或實地看。
* 預算篩選比的是各區中位總價，不是個別物件。
* 淹水潛勢沒有內建，只有外部連結。
* 地形為約 1.1 公里格網，細節有限；要看精細地形請用「Google 地形圖」按鈕。
* 本工具只整理公開資訊供看屋參考，不構成投資或購屋建議。
