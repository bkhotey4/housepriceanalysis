# 台灣房價分析（deep_tainan_house）

全台各縣市、鄉鎮與路段的實價登錄行情，畫在 3D 地圖上；加上重大建設時程、通勤、周邊設施、估價與房貸試算。
是一個純靜態網頁（`web/` 資料夾），所有計算都在使用者自己的手機、平板或電腦上完成，不需要伺服器。

**網址：https://bkhotey4.github.io/housepriceanalysis/**

> 舊的 Tkinter 桌面版已經移除（功能全部由網頁版取代）。`app.py` 現在是網頁版的啟動器。

## 怎麼開

* **手機、平板、電腦**：直接用瀏覽器打開上面的網址。手機瀏覽器選單裡的「加到主畫面」，之後就像 App 一樣開啟，沒網路也能開（用上次看過的資料）。
* **Windows 電腦**：在專案資料夾按兩下 `run_app.bat`（或 `python app.py`）。
  有網路時打開線上版（全台資料、每月自動更新）；沒網路時自動在本機開 `web/` 資料夾。
* **一律用本機的檔案**（離線、或測試自己改過的程式）：`python app.py --local`。會在 `http://127.0.0.1:8000/` 開一個只有這台電腦連得到的小伺服器，
  關掉視窗或按 Ctrl+C 結束。本機的 `web/data` 預設只有臺南市；要全台資料先執行 `python tools/export_tw.py --update`（約 300MB 下載）。
  直接雙擊 `web/index.html` 不行，瀏覽器不允許網頁從 file:// 讀資料檔。
* 網站更新後，再打開時上方會出現「網站有新版本」，按「重新整理」就是新版。

## 有哪些功能

右側（手機是下方抽屜）的分頁：

| 分頁 | 做什麼 |
|---|---|
| 概況 | 每月中位價走勢、價格分佈、市場冷熱、樓層價差、屋齡與單價、車位行情、房貸／新青安試算、交屋前現金、租金行情、買房 vs 租房 |
| 排行 | 各區（或各縣市）房價排行，可依預算、通勤篩選；填了家庭收入會多一欄「不吃不喝幾年」 |
| 通勤 | 設定上班地點與交通方式（開車／機車／腳踏車），看各區依實際道路算的通勤時間 |
| 路段 | 各路段的件數與中位價；地圖上的道路依價格上色 |
| 社區 | 同門牌（同一棟）或同建案的成交：每季單價、各樓層單價；預售屋另列解約筆數與比例 |
| 成交 | 逐筆成交；搜尋地址時依門牌遠近排列 |
| 估價 | 輸入坪數、屋齡、樓層、車位、路名，從相近的成交算合理價區間與建議出價 |
| 比較 | 任選 2～3 個區（可跨縣市）並排比較，兩區時有「雙區 PK」 |
| 建設 | 重大建設的時程（附來源），地圖上有 3D 圖案與年份滑桿 |
| 周邊 | 搜尋地址後查周邊生活機能、嫌惡設施、最近的國小國中（OpenStreetMap） |
| 看屋 | 自己的看屋清單：和行情比較、附近有新成交時提醒，可匯出／匯入備份 |

其他：

* **搜尋**：上方搜尋框可以打地址、路名、行政區、學校或地標，邊打邊出現建議。
* **設定（☰）**：圖層（行政區界、土壤液化、山崩地滑、活動斷層、捷運、地標、建設…）、柱子顏色（價格、漲跌、租金報酬率、市場冷熱）、
  外觀（淺色／深色）、預算與上班地點；也可以用家庭月收入和可用現金反推預算。
* **分享**：地圖右側的「分享」會產生目前畫面（縣市、區、房型、分頁）的連結。
* **行情報告**：概況的「行情報告」產生一頁可以列印成 PDF 的報告。
* 鍵盤：分頁可以用左右鍵、Home、End 切換；Esc 關閉設定。

## 資料

* **房價**：內政部不動產交易實價查詢服務網的開放資料（不動產買賣、預售屋、租賃）。只算住宅的房地交易，排除親友、持分、急買急賣等特殊交易；統計值都是中位數。
  實價登錄從成交到公開約慢 1～2 個月，最近一個月件數偏少（圖上用空心點表示）。透天厝的單價含土地，看透天請以總價為主。
* **樓層、車位、解約**：從實價登錄的「移轉層次」「車位類別／面積／總價」「解約情形」欄位整理。樓層價差是「同一棟裡比」，
  車位行情只算車位價格有分開登錄的成交。
* **道路位置、周邊設施、捷運高鐵路線**：© OpenStreetMap 貢獻者。門牌位置是依道路推估的，不是精確座標。
* **通勤時間**：[OSRM](https://project-osrm.org/)（FOSSGIS 的公開路線伺服器，OpenStreetMap 道路）。每個「上班地點＋交通方式＋縣市」只查一次，結果存在裝置上 30 天；
  開車、機車另乘尖峰係數（1.25、1.15），再加出發與停車時間。伺服器連不上時退回直線距離估算。
* **房價所得比**：各區中位總價 ÷ 使用者自己填的家庭年收入。官方的全國與各縣市房價所得比請看[內政部不動產資訊平台](https://pip.moi.gov.tw/Publicize/Info/Index)。
* **影像、行政區界**：內政部國土測繪中心。**土壤液化、山崩地滑、活動斷層**：經濟部地質調查及礦業管理中心。
* **淹水潛勢**：官方圖資不開放疊圖，網站上是連到國家災害防救科技中心的連結。
* **重大建設、議會、建商情資**：`data/intel.json`、`data/mrt.json`，每一筆都附來源。

### 資料怎麼更新

* **實價登錄**：GitHub Actions 每月 2、12、22 日（內政部 1、11、21 日發布）自動下載、重新統計並部署（`.github/workflows/pages.yml`，
  實際步驟在 `tools/ci.sh`）。每次 push 到 main 也會跑一次。執行紀錄在 `logs/ci/latest.md`，有步驟失敗會自動開 Issue。
* **情資、捷運**：改 `data/intel.json`、`data/mrt.json` 後執行 `python tools/check_data.py` 檢查格式，再 commit、push。
* 部署卡住（Actions 裡有一次一直是「Waiting」，後面的都在排隊）時：點進那一次 →右上角「⋯」→「Cancel workflow」。

## 怎麼測試

按兩下 `run_tests.bat`（或 `python tests/run_all.py`），最後一行出現「全部通過」即正常；完整結果存在 `tests/last_result.txt`。

* `test_core`、`test_features`、`test_taiwan`：實價登錄解析、統計、道路與門牌、全台下載、租金、資料更新流程（用假資料，不連網）。
* `test_web`、`test_search_autocomplete`：用瀏覽器（Playwright）實際操作網頁版，並比對網頁和 Python 算出來的數字一致。沒裝 Playwright 會略過。
* `test_app`：啟動器的本機伺服器。

## 檔案結構

```
web/                   網頁版（index.html、css/、js/、data/、img/）；說明見 web/README.md
app.py、run_app.bat    啟動器：用瀏覽器打開網頁版
core/                  實價登錄下載與解析、房價統計、租金、地址與門牌、道路、地標與建設、底圖與疊圖、全台縣市清單、資料檢查
tools/                 產生網頁資料（export_web.py 台南、export_tw.py 全台）、道路與鄉鎮清單、捷運高鐵路線、CI 流程
data/                  情資、捷運、地標、行政區、上班地點等原始資料；data/cache/ 是下載快取（不進 git）
tests/                 自動測試
logs/ci/               自動更新的執行紀錄
```

## 已知限制

* 捷運站位、開發案位置、上班地點都是估算值，僅供示意；通勤時間算到各區中心，沒有即時路況，也沒有大眾運輸。
* 路段房價是把門牌上的路名對到 OpenStreetMap 的道路；長的路整條是同一個中位價。
* 學區是依門牌劃分的，網站列的「最近的國小國中」只是參考，請以縣市教育局的學區查詢為準。
* 預算篩選比的是各區中位總價，不是個別物件。
* 本工具只整理公開資訊供看屋參考，不構成投資或購屋建議。
